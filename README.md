> 麦当劳 MCP 驱动的「赛博玄学」点餐 Skill —— WorkBuddy「1024 造物挑战」程序员节应用创作大赛参赛作品

把中国互联网两大显学——**老黄历**和**麦门**——焊在一起：

选一下今日状态（周一综合症 / 带薪如厕 / 发工资日……），罗盘一转，

## 🔑 真实模式（接入麦当劳 MCP）

1. 到 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 用手机号申请 Token
2. 三选一配置（都不写进代码）：
   - 环境变量：`set MCD_MCP_TOKEN=你的Token`（Windows）
   - 本地 `.env` 文件：`MCD_MCP_TOKEN=你的Token`（已被 .gitignore 忽略）
3. 跑：

```bash
python LaoHuangLi.py --state 周一综合症 --city 上海 --keyword 麦当劳
```

真实模式下，运势卡的日期、优惠券、营养数据、门店全部来自麦当劳中国官方 MCP。

## 🎮 玩法设计

- **8 种今日状态**：周一综合症 / 带薪如厕 / 周末躺平 / 减肥第三天 / 失恋第7天 / 加班夜归人 / 发工资日 / 考前突击，每种都有专属宜忌与吐槽理由
- **6 档吉凶**：大吉 / 中吉 / 小吉 / 半吉 / 平 / 凶（大凶也附解法：「宜呼友共食，可破」）
- **有券升档**：今日可领券命中「宜」的事项，运势升一档——黄历每天不一样，因为**真实优惠券每天在轮换**
- **不代付**：本工具只出建议，不调用下单，支付由用户自行确认

## 🧱 技术架构

```
MaiMenLaoHuangLi/
├── index.html              # 赛博黄历 demo 网页（单文件，GitHub Pages 可直达）
├── LaoHuangLi.py           # 命令行入口：参数解析、数据编排、运势卡渲染
├── YunQiYinQing.py         # 运势引擎：状态/吉凶/套餐 + 有券升档 + 营养别名匹配
├── McpKeHu.py              # MCP 客户端：零依赖 Streamable HTTP，兼容 JSON/SSE
├── CanPinShuJu.py          # 演示数据：无 Token 时的离线替代（结构与真实返回一致）
├── CeShi.py                # 离线自测：19 项断言，python CeShi.py 一键跑
├── MCP_INTEGRATION.md      # MCP 集成说明
├── CONTEST_DECLARATION.md  # 参赛原创性声明
└── workbuddy.md            # WorkBuddy 开发记录
```

- Python 3.9+，**零第三方依赖**，`python CeShi.py` 可离线验证
- 单工具调用失败自动降级，不影响主流程
- 网页版额外接入 WorkBuddy 云服务：抽签记录与功德数据实时入库，全站签运与功德池可共享
